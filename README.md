# Panda Earth (2018) — wrapped NFT metadata

Hosts the metadata and images for the Panda Earth wrapper contract
`0x0910ec6120316daa6539643474d2087c13f0c494` (OpenSea: `pandaearthofficial`).

- `metadata/<tokenId>` — ERC-721 JSON for each wrapped panda
- `images/<tokenId>.png` — the panda image

Served via GitHub Pages so marketplaces can load a stable URL.
Contributions come in as pull requests and are reviewed before merging.
